## Problem
A Musanze potato cooperative needs to (1) estimate harvest quantity (regression), (2) flag farms at high production
risk, i.e. yield per hectare below the median (classification), and (3) group farms with similar conditions
(clustering). Training and CLI prediction work offline; a FastAPI service allows later mobile integration.

## Setup and run
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate      macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run_all.py --student-id ug2528075@ines.ac.rw --seed 8075
python predict.py --json samples/valid.json
python predict.py --json samples/invalid.json      # shows validation errors (exit code 2)
pytest -q
uvicorn app:app --host 127.0.0.1 --port 8000       # docs at http://127.0.0.1:8000/docs
```
`run_all.py` rejects any seed that is not the last four digits of the student id (e.g. `--seed 4671` is refused).

**Expo / mobile client:** run `uvicorn app:app --host 0.0.0.0 --port 8000`, then call `http://<your-PC-LAN-IP>:8000/predict`
with `fetch` from the app (phone and PC on the same Wi-Fi). CORS is open for development only. The Expo version is not
needed by this assignment; the API is plain HTTP/JSON.

## Known limitations
Synthetic data; linear-ish formula so Ridge wins; K-means finds no real clusters; median imputation hides imputed values;
the high_risk label uses the whole-sample median (as the assignment defines it); prototype CORS is open.
